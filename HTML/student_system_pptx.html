📝 Data Models

StudentCreate (Input)

class StudentCreate(BaseModel): name: str grade: int

Used for POST and PUT requests

Student (Output)

class Student(BaseModel): id: int name: str grade: int

Includes auto-generated ID

⚠️ Important Fix: Separated models to avoid 422 errors. When creating students, ID is auto-generated by the database, so it shouldn't be in the input model.

🗄️ Database Setup

def setup_database(): conn = sqlite3.connect('students.db') cursor = conn.cursor() cursor.execute(''' CREATE TABLE IF NOT EXISTS students ( id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL, grade INTEGER ) ''') conn.commit() conn.close()

Database Schema:

Column Type Description
id INTEGER Primary key, auto-increment
name TEXT Student name (required)
grade INTEGER Student grade (0-100)

🔌 REST API Endpoints

Method Endpoint Purpose
GET /students/ Fetch all students
POST /students/ Create new student
PUT /students/{id} Update existing student
DELETE /students/{id} Delete student

Example: Create Student (POST)

@app.post("/students/") async def create_student(student: StudentCreate): conn = sqlite3.connect('students.db') cursor = conn.cursor() cursor.execute("INSERT INTO students (name, grade) VALUES (?, ?)", (student.name, student.grade)) conn.commit() return {"message": "Student added successfully"}
